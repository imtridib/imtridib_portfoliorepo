## ⚡ Quick Start

```bash
# Clone the repository
git clone https://github.com/imtridib/imtridib_portfoliorepo.git
cd imtridib_portfoliorepo

# Install dependencies
npm install

# Start development server
npm run dev

# Type-check & production build
npm run build
```

## 📂 Project Structure

```
src/
├── main.tsx                 # React entry point
├── App.tsx                  # Root component — assembles all sections
├── index.css                # Global styles & Tailwind config
├── components/
│   ├── layout/              # TopBar, Dock (macOS-style nav)
│   ├── sections/            # Hero · Projects · Skills · Research · About · Contact
│   └── ui/                  # Reusable primitives (cards, modals, animations, shaders)
├── data/                    # All portfolio content (projects, skills, research, socials)
├── hooks/                   # useTheme · useActiveSection · useDockMagnify
├── types/                   # Shared TypeScript interfaces
└── icons/                   # Custom SVG icon components
```

> **Tip:** To update portfolio content, edit the files in `src/data/`. Theme colors live in `src/index.css`. Place images in `public/images/`.
