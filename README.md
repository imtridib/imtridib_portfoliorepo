# Robert Garcia – Portfolio

React + TypeScript + Tailwind CSS (v3) + Vite.

    npm install
    npm run dev       # start dev server
    npm run build     # type-check + production build

Add your images to `public/images/` (portrait.png, projects/project-1..3.png).
Edit content in `src/data/`. Theme colors live in `src/index.css`.
